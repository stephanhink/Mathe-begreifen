Keine Datenerhebung

Diese App erhebt, überträgt und verarbeitet keinerlei personenbezogene Daten. Sie funktioniert vollständig offline auf deinem Gerät:

  • Es gibt keine Nutzerkonten und keine Anmeldung.
  • Es werden keine Daten an Server oder an Dritte übertragen.
  • Es werden keine Analyse-, Tracking- oder Werbe-Dienste eingebunden.
  • Es gibt keine In-App-Käufe.
  • Es wird keine Internetverbindung benötigt.

Der Lernstand bleibt auf dem Gerät

Damit du beim nächsten Start dort weitermachen kannst, wo du aufgehört hast, speichert die App deinen Lernstand. Diese Daten verlassen dein Gerät nicht: Sie liegen im lokalen Speicher der App und werden nirgendwohin gesendet.

Gespeichert wird ausschließlich, was zum Wiederfinden des Lernstands nötig ist — kein Name, keine E-Mail-Adresse, keine Gerätekennung, keine Uhrzeit, keine Standortdaten. Ein Eintrag sieht vollständig so aus:

{ "bruchKuerzen": { "versuche": 3, "richtig": 2, "fach": 2, "zuletzt": "2026-08-03", "faellig": "2026-08-10" } }

Also: welches Thema, wie oft geübt, wie oft richtig, in welchem Lernkartenfach es liegt und wann es wieder dran ist. Ein Rückschluss auf eine Person ist daraus nicht möglich — die Daten enthalten kein Merkmal, das jemanden bezeichnet.

Du kannst den Lernstand jederzeit selbst löschen: im Lückenfinder über den Knopf „Lernstand löschen“. Beim Deinstallieren der App wird er ebenfalls vollständig entfernt. Da die Daten das Gerät nie verlassen, gibt es nichts, was darüber hinaus zu löschen wäre.

Berechtigungen

Die App benötigt keine besonderen Geräteberechtigungen — keine Kamera, keinen Standort, keine Kontakte, kein Mikrofon, keinen Zugriff auf Dateien.

Im Play Store wird als einzige Berechtigung INTERNET aufgeführt. Die App nutzt sie nicht: Sie ruft keine Server auf und lädt nichts nach. Die Berechtigung ist ausschließlich deshalb enthalten, weil Android sie verlangt, damit die App später über den Play Store aktualisiert werden kann.

Lernhilfe, kein Ersatz für den Unterricht

Diese App dient ausschließlich Lern- und Übungszwecken. Sie ersetzt weder den Unterricht noch die Erklärung durch eine Lehrkraft. Ergebnisse sollten, besonders vor Klassenarbeiten und Prüfungen, nachgerechnet werden.

Minderjährige Nutzerinnen und Nutzer

Die App richtet sich an Schülerinnen und Schüler ab Klasse 5. Sie wird also ausdrücklich auch von Kindern genutzt. Genau deshalb ist sie so gebaut, dass sie ohne jede Datenerhebung auskommt: Es gibt keine Anmeldung, keinen Server und keine Möglichkeit, mit anderen Personen in Kontakt zu treten.

Eine Einwilligung der Eltern nach Art. 8 DSGVO ist nicht erforderlich, weil keine personenbezogenen Daten verarbeitet werden. Lernstände dokumentieren Schwächen und sind deshalb heikel — sie bleiben aus diesem Grund ausschließlich auf dem Gerät des Kindes.

Deine Rechte

Nach der DSGVO stehen dir Auskunft, Berichtigung, Löschung, Einschränkung, Datenübertragbarkeit und Widerspruch zu, dazu das Recht auf Beschwerde bei einer Aufsichtsbehörde. Da diese App keine personenbezogenen Daten verarbeitet, liegen jedoch keine Daten vor, auf die sich diese Rechte beziehen könnten. Bei Fragen kannst du dich jederzeit an die oben genannte E-Mail-Adresse wenden.

Änderungen dieser Datenschutzerklärung
